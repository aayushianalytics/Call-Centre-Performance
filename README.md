# Call-Centre-Performance-Dashboard | Excel


## 📌 Project Overview
Call centers handle large volumes of customer interactions every day, making it difficult to track agent performance, customer satisfaction, and operational efficiency manually. This Excel dashboard was built to organize and analyze call centre data in one place, helping users monitor performance trends and improve reporting efficiency.


## 🛠 Tech Stack
**Microsoft Excel** – Used to build the interactive dashboard and perform overall data analysis.
**Pivot Tables** – Used to summarize and analyze large volumes of call centre data efficiently.
**Power Query** – Used for cleaning and transforming raw customer interaction data.


## 📂 Dataset
The dataset includes customer call records, agent performance details, call durations, customer satisfaction ratings, and transaction-related information used for call centre performance analysis.


## 📋 Features
### ⚠️ Business Problem
Managing customer support data manually across multiple agents and interactions can become difficult and time-consuming. It becomes challenging to track customer satisfaction, identify performance gaps, and monitor overall operational efficiency effectively.

### 🎯 Goal of Dashboard
The goal was to build an interactive dashboard that provides a complete overview of call centre performance, helping users monitor agent activity, customer satisfaction, and call handling trends more efficiently.

### 📊 Key Visuals
- **KPI Cards (Top Section)** Displays overall calls handled, average ratings, total revenue, and other key performance metrics for a quick operational overview.
- **Call Trend Analysis (Charts)** Shows trends in customer interactions and call volumes across different time periods to identify workload patterns.
- **Agent Performance Breakdown (Bar Charts)** Highlights individual agent performance based on calls handled, ratings, and efficiency metrics.
- **Customer Satisfaction Analysis (Visuals)** Helps track customer experience and identify areas where service quality may be improving or declining.
- **Call Duration & Transaction Insights (Charts)** Analyzes average handling time and transaction-related performance indicators.
- **Interactive Filters & Slicers** Allows users to filter the dashboard dynamically by agent, topic, and other categories for more focused analysis.

### 📈 Business Impact and Insights
- Helped identify top-performing agents based on ratings and productivity
- Improved visibility into customer satisfaction and operational performance
- Made it easier to analyze call handling trends and workload distribution
- Reduced manual reporting efforts through centralized dashboard reporting
- Enabled quicker performance monitoring and data-driven operational analysis
